basalt rolling packages and sources

What this is

This site holds the rolling backup of the packages, and the sources they are built from, that make up basalt, the first-party distribution of the nife operating system. Each time basalt publishes, it puts these files here, and the same files at its second address. The package index is the one a nife system reads when it installs packages, and the copy of each package here is the one tried when the primary location cannot be reached.

Only the newest build is kept here. Older versions stay on basalt's releases.
